1. Executive Summary & Architecture

The Campus Event Manager is a multi-tier platform engineered for managing university events, participant tracking, and real-time operational analytics built using the MVC pattern on Express.js and MongoDB Atlas.

LayerTechnologyImplementation Details
Backend RuntimeNode.js / Express.jsHandles REST routing, middleware request validation, dynamic template processing.
Database LayerMongoDB Atlas / Mongoose ODMDocument persistence store for user entities and embedded event registration arrays.
Front-End LayerEJS & Bootstrap 5Server-rendered dynamic templates with responsive desktop/mobile UI components.
Data AnalyticsMongoDB AggregationsExecutes multi-stage analytical queries ($unwind, $group, $lookup, $project).

3. MongoDB Aggregation Pipelines

3.1 Analytics Dashboard View

Figure 5: Analytics UI showing operational data aggregations.

Query 1: Total Registrations by Category

db.events.aggregate([ { $unwind: "$registrations" }, { $group: { _id: "$category", totalEvents: { $addToSet: "$_id" }, confirmedRegistrations: { $sum: 1 } } }, { $project: { category: "$_id", eventsCount: { $size: "$totalEvents" }, confirmedRegistrations: 1, _id: 0 } }, { $sort: { confirmedRegistrations: -1 } } ]);

Query 2: Top 5 Events by Occupancy Rate

db.events.aggregate([ { $project: { title: 1, category: 1, capacity: 1, registrationsCount: { $size: { $ifNull: ["$registrations", []] } }, occupancyRate: { $multiply: [ { $divide: [ { $size: { $ifNull: ["$registrations", []] } }, "$capacity" ] }, 100 ] } } }, { $sort: { occupancyRate: -1 } }, { $limit: 5 } ]);

Query 3: Inactive Users Search

db.users.aggregate([ { $lookup: { from: "events", localField: "_id", foreignField: "registrations.userId", as: "userEvents" } }, { $match: { userEvents: { $size: 0 } } }, { $project: { firstName: 1, lastName: 1, email: 1, role: 1 } } ]);
